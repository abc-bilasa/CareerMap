# CareerMap MVP — Futuristic Edition

A no-login, browser-only prototype that maps a person's life story and optional resume text against 100 career-success factors.

## Run

Open `index.html` directly, or run a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features
- 100-factor capability map
- Life story + optional resume input
- Rule-based evidence matching
- Strong / Some Evidence / Not Found states
- Category dashboard
- Factor explorer and filters
- 90-day evidence-building prompts
- localStorage persistence
- No login, backend, database or AI API
- Futuristic black / white / gray / gold UI

## Note
This is a heuristic prototype, not a validated psychometric, hiring, or career assessment. Matching is based on language evidence and should be reviewed by the user.
